# Fair Lend Credit Analytics ⚖️💳

A FinTech Data Science project focused on credit risk assessment and algorithmic fairness using Machine Learning.

## 📌 Project Overview
This repository contains a credit scoring model designed to predict loan approval while ensuring algorithmic fairness. Coming from a **Mathematics and Chartered Accountancy (CA Inter)** background, I bridged the gap between financial risk principles and data science by building a transparent, unbiased machine learning system.

## 🛠️ Tech Stack & Methods
- **Language:** Python (Google Colab / Jupyter Notebook)
- **Model:** XGBoost Classifier (for high-accuracy credit scoring)
- **Explainable AI:** SHAP (SHapley Additive exPlanations) to interpret model decisions and ensure fairness.
- **Dataset:** 10,000 synthetic borrower financial records.

## 📊 Key Outcomes & Results
The model successfully processes financial inputs (income, credit score, debt-to-income ratio) and outputs a fair credit decision.
- **Model Accuracy:** 77.24% (Demonstrates strong and reliable predictive power on the financial dataset).
- **Interpretability:** Used SHAP plots to audit the model and ensure decisions are clear, explainable, and fair.
