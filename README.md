# Bank Loan Prediction & Risk Analysis Dashboard

This repository contains a comprehensive Data Science application designed to predict bank loan approval eligibility and evaluate financial credit risks. This project was developed as a core requirement for my Master's framework.

## 🚀 Key Features
* **Predictive Modeling:** Implements classification algorithms to determine loan approval with optimized accuracy.
* **Exploratory Data Analysis (EDA):** Detailed statistical analysis and visual profiling of applicant demographics and financial history.
* **Interactive Development:** Modeled and validated using standard Python environments like Google Colab and Kaggle.
* **Data Pipeline:** Complete automation for handling missing values, feature engineering, and model evaluation metrics.

## 🛠️ Tech Stack & Tools
* **Programming Language:** Python
* **Environments:** Google Colab, Kaggle Notebooks
* **Core Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Methodology:** AI-assisted development for code architecture and logical flow optimization.

## 📊 Model Evaluation
* **Dataset Source:** Kaggle Bank Loan Datasets
* **Target Variable:** Loan Status (Approved / Rejected)
* **Performance Metrics:** Classification Report, Confusion Matrix, and Accuracy Scores.

## 💻 How to Run the Project
1. Open the `.ipynb` notebook file directly in **Google Colab** or **Kaggle**.
2. Download and upload the corresponding bank loan dataset.
3. Run all cells sequentially to generate the statistical visualizations and train the predictive model.
